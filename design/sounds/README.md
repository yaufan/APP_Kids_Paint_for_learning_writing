# 字母寵物的聲音

所有聲音都是用程式合成的（numpy、scipy）：沒有錄音、沒有下載別人的素材，曲子都是為這個 APP 新寫的。合成用的小工具（鐘聲、木琴、音樂盒、動物叫聲的共鳴方法）是從畫畫小鎮的 `docs/design/sounds/make_sounds.py` 複製過來的。

## 怎麼產生

```
pip install numpy scipy               # 只要第一次
python3 design/sounds/make_sounds.py  # 寫到 app/assets/sounds/*.wav
```

跑完會印出每個檔案的長度、大小、音量、有沒有破音，還有背景音樂接頭的檢查。亂數都用固定的種子，每次跑出來的檔案都一模一樣。

## 格式
- 全部是 WAV、單聲道、16 位元。
- 背景音樂 16,000 Hz；音效和寵物叫聲 22,050 Hz。
- 背景音樂可以無縫循環：曲子結尾還在響的聲音接回開頭，聽不出接縫。
- 音量（滿格是 1）：背景音樂最大約 0.24～0.3，音效約 0.5～0.72。音效兩頭都有淡入淡出，不會「啪」一聲。
- 全部加起來約 3.8 MB（3,983,742 bytes），在 4 MB 以內。

## 背景音樂

| 檔案 | 用在哪裡 | 長度 | 聽起來 |
|---|---|---|---|
| `music_home_land` | 陸地寵物的家（小狗、小貓、小兔、小恐龍） | 21.6 秒 | F 大調，木琴加音樂盒，輕快開心；後半段換音樂盒唱旋律、木琴伴奏 |
| `music_home_sea` | 海裡寵物的家（小海豚、小章魚、小海龜） | 21.6 秒 | D 大調，豎琴像海浪一樣上下滾動，慢慢的旋律，輕輕冒泡泡 |
| `music_write` | 寫字 | 21.1 秒 | 很安靜、音很少的柔和鋼琴（木琴和鐘聲混出來的），低低的，不吵 |
| `music_play` | 照顧和玩 | 16 秒 | G 大調，活潑跳跳的木琴，「蹦－恰」的低音、小鼓和沙鈴 |
| `music_sleep` | 睡覺 | 21.1 秒 | C 大調三拍子的慢搖籃曲：音樂盒，豎琴輕輕搖，溫暖的和聲 |

背景音樂沒有做到 24 秒：16,000 Hz 的聲音 1 秒是 32 KB，四首 24 秒加一首 16 秒就有 3.6 MB，再加上音效會超過 4 MB。所以四首做成剛好整數小節的 21～22 秒。

## 寵物叫聲

| 檔案 | 寵物 | 聽起來 |
|---|---|---|
| `call_puppy` | 小狗 | 汪汪（小狗的高音） |
| `call_kitten` | 小貓 | 細細的「喵～」 |
| `call_bunny` | 小兔 | 嗅嗅，再吱吱兩聲 |
| `call_dino` | 小恐龍 | 小小可愛的「吼～」 |
| `call_dolphin` | 小海豚 | 一串喀喀聲，再一聲口哨 |
| `call_octopus` | 小章魚 | 咕嚕咕嚕冒泡泡 |
| `call_turtle` | 小海龜 | 開心的「嗯～哼」，加一個泡泡 |

動物的聲音和畫畫小鎮一樣：用一個嗡嗡聲（聲帶）通過幾個共鳴（嘴巴的形狀），做出「喵」「汪」這些母音。
