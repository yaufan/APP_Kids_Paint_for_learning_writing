# 字的寫法：筆順和方向

我沒有找到教育部對英文字母筆順的正式規範，所以選了一套台灣國小課本和幼兒教材常見的「圓和直線」印刷體寫法。原則：

- 直線一律由上往下，橫線一律由左往右。
- 圓和彎的線從上面開始，逆時針（往左）繞。
- 一筆能寫完的就一筆（L、V、W、Z、U、S、C、O）。
- 有直線的字先寫直線，再寫彎的或橫的（B、D、P、R、E、F、H）。

資料在 `design/glyphs/glyphs.py`（產生 `app/assets/glyphs.json`）。每個字高 100，起點和方向都在裡面；`python3 glyphs.py preview 輸出.png` 可以看到每一筆的起點（綠點）和方向（紅線）。
